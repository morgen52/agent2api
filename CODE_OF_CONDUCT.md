# Code of Conduct

This project follows a simple standard: be direct, technical, and respectful. Contributions should focus on the work, the evidence, and the tradeoffs.

## Expected Behavior

- Use clear language and assume good intent.
- Keep review feedback specific and actionable.
- Respect different experience levels and backgrounds.
- Disclose security concerns responsibly.
- Avoid harassment, personal attacks, and discriminatory language.

## Unacceptable Behavior

- Insults, threats, stalking, or sustained disruption.
- Publishing private information without permission.
- Sexualized language or unwelcome attention.
- Dismissing security or safety issues without technical evaluation.

Maintainers may moderate issues, discussions, and pull requests to keep the project useful and safe for contributors.
