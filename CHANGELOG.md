# Changelog

All notable changes to Agent2API are documented here. This project follows a simple human-readable changelog until a formal release process is introduced.

## 0.1.0 - Initial Public Release

- Added the Agent Task Protocol for agent-level HTTP requests.
- Added the Fastify API server with sync runs, async runs, polling, artifact downloads, and SSE run events.
- Added the Codex CLI adapter.
- Added the browser and Node JS/TS SDK at `agent2api/sdk`.
- Added README visuals, API docs, protocol docs, architecture docs, CI, tests, and open-source governance files.
