# Changelog

All notable changes to Agent2API are documented here. This project follows a simple human-readable changelog until a formal release process is introduced.

## 0.1.0 - Initial Public Release

- Added the Agent Task Protocol for agent-level HTTP requests.
- Added the Fastify API server with sync runs, async runs, polling, persistent run records, artifact downloads, SSE run events, cancellation, queueing, multipart uploads, skill registry endpoints, optional bearer-token auth, retention cleanup, and JSONL audit logs.
- Added the Codex CLI adapter and local shell adapter.
- Added the browser and Node JS/TS SDK at `agent2api/sdk`, including run creation, multipart upload, polling, cancellation, artifact download, SSE streaming, and skill helpers.
- Added README visuals, API docs, protocol docs, architecture docs, CI, tests, and open-source governance files.
